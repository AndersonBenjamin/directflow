Política de Privacidade

Modelo inicial — revise com seu jurídico e substitua [EMPRESA] e [CONTATO] antes do App Review.

Quais dados tratamos

Quando alguém comenta em uma publicação com automação ativa, recebemos da Meta o ID e o nome de usuário do autor, o ID e o texto do comentário. Usamos esses dados apenas para enviar uma única mensagem direta com o link solicitado e para registrar o histórico de envio.

Por quanto tempo

O histórico de comentários é apagado automaticamente após 90 dias. Tokens de acesso são guardados criptografados e removidos quando a conta é desconectada.

Compartilhamento

Não vendemos nem compartilhamos esses dados com terceiros. O processamento acontece somente pela API oficial da Meta.

Exclusão de dados

Para pedir a exclusão dos seus dados, envie uma mensagem para [CONTATO] informando seu nome de usuário do Instagram. A exclusão é feita em até 30 dias. Administradores podem remover todos os dados da conta clicando em “Desconectar” no painel.
